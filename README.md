# Abartılı Motivasyon Robotu

**DÜNYANIN EN CİDDİ, EN GEREKSİZ VE EN ÇALIŞAN MOTİVASYON SİSTEMİ**

Bu depo, insanlığın en büyük sorununu çözmek için tasarlanmıştır: **Motivasyon eksikliği.**

Artık kimse "yapamıyorum" diyemeyecek. Çünkü bu robot, o kadar abartılı motivasyon verir ki, kod yazmaktan başka seçeneğin kalmaz. Kahve içmeden çalışmaz ama çalışır. İnanmıyorsan çalıştır.

## Nasıl Kullanılır?

```bash
python motivasyon.py
```

Evet, bu kadar. Basit. Güçlü. Abartılı.

## Özellikler

- Rastgele, aşırı abartılı Türkçe motivasyon mesajları
- %100 çalışan kod (test edildi, kahve içildi)
- Hiçbir işe yaramaz ama eğlenceli
- Gizli özellikler içerir (bulursan bulursun)

## Uyarı

Bu robotu kullandıktan sonra kendinizi evrenin efendisi gibi hissedebilirsiniz. Sorumluluk size aittir.
